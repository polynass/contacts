# 📱 Contacts & Calls (Android App)

**A simple app to view device contacts and make quick calls.**

## Key Features
- View contacts from the device
- Contacts grouped by first letter
- Tap to call functionality
- Permission handling and error checks

## Technologies
- **Language:** Kotlin
- **Architecture:** MVVM
- **Libraries:** Jetpack Compose, AndroidX ViewModel, Permissions API

## Requirements
- Android 8.0+ (API 26)
- Permissions:
  - `READ_CONTACTS`
  - `CALL_PHONE`

## Installation
1. Clone the repository
2. Open in Android Studio
3. Build and run on device/emulator
